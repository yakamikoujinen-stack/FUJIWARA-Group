# FUJIWARA Group お金管理

入口は `../fujiwara-money.html`。KINGの「管理・個人ツール」から同じ画面を開く。ログイン後、社長には共有帳簿とスタッフ申請を表示し、スタッフには申請フォームと本人の申請を表示する。

## 接続

1. 新規の Firebase プロジェクトをお金管理専用に用意する。プロジェクトIDは `fujiwara-money` または `fujiwara-money-…`。デフォルトの Realtime Database をロックモードで作成し、`database.rules.json` をそのデータベースに適用する。
2. Firebase Authentication のメール／パスワードを有効にし、社長とスタッフに個別のアカウントを作る。`moneyV1/roles/<Firebase Auth UID>` に文字列の `ceo` または `staff` を設定する。利用者の画面から役割は編集できない。
3. ウェブアプリを登録する。Firebase のクライアント設定オブジェクトを JSON として初回設定欄で読み込める。公開時は同じ JSON を `money/firebase-config.json` に置くと、PCとiPadで設定ファイルを選び直す操作が不要になる。置くのはウェブ用の設定だけ。サービスアカウント鍵、パスワード、実伝票はGitHubに入れない。

## 実機確認と移行

- iPad Safari、Windows Chromeを同じ社長アカウントで開く。紙の表から月をまたぐ試験伝票を保存し、反対側に表示されることと「対象月」で絞り込めることを確認する。
- 2台で同じ伝票の編集を開き、先に一方から保存する。もう一方で古い内容を保存すると拒否されることを確認する。
- スタッフから試験写真付きで申請する。社長が内容を確認し、所属先と科目を選んで帳簿に保存する。スタッフの画面に確認結果が出ること、別のスタッフの申請と共有帳簿に閲覧権限がないことを確認する。
- 試験用データベースで検証を済ませた後、実運用用の専用データベースに接続する。既存仮帳簿から最後に取った暗号化JSONを社長画面で選び、元の合言葉で検証する。追加件数と合計を確認して取り込み、両端末で照合する。再取り込みは同一ID・同一内容を除外し、内容が異なる場合は中断する。
- 取り込みの対象は仮帳簿の伝票と縮小写真。旧会計v1.9の別バックアップにある管理メモと、試験環境のレシート申請はそれぞれ別データとして扱う。

クラウド上の閲覧・編集は Firebase のアクセスルールで制御する。ダウンロード用バックアップのみ従来と同じ合言葉で暗号化する。現行バックアップとの互換性のため、書き出し上限は4,000件または16MB。集計は伝票日付に基づく表示中伝票の金額で、請求書や納品書も含む。
