🔐 FUJIWARA 隔離Firebase 実保存試験

2026年11月3日｜v1.0｜別プロジェクト専用・正規アプリへの変更なし

① 最重要：本番とは完全分離

FUJIWARA本番のFirebase設定は絶対に入力しないでください。本番プロジェクト fujiwara-group-3a600 への接続は、アプリ側で拒否します。既存のRealtime Databaseのルールも変更しません。

新規Firebaseプロジェクトを別に作成し、Realtime Databaseとメール/パスワード認証を有効化して使用します。旧データのコピーや本番アカウントの引き継ぎは不要です。

まだ別プロジェクトがなければ、②以降の入力・操作をしないでください。画面の見た目と手順だけ確認できます。

② 新しい試験専用プロジェクトの準備

  1. Firebaseコンソールで新規プロジェクトを作る。名前の例：FUJIWARA-SANDBOX（既存のFUJIWARA-Groupは選ばない）。
  2. そのプロジェクトのAuthentication → ログイン方法で「メール/パスワード」を有効化し、試験用ユーザーを作成する。本番用パスワードは使わない。
  3. Realtime Databaseを新規作成。公開モードにせず、下の専用ルールをセットする（テストプロジェクト内だけ）。
  4. 「プロジェクトの設定 → 全般 → ウェブアプリ」でFirebase構成の6項目を確認して入力する。設定値に本番のデータベースURLを混ぜないこと。

試験用Realtime Databaseルール（試験プロジェクトにのみ設定）

{
  "rules": {
    ".read": false,
    ".write": false,
    "sandbox_auth_test_v1": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid",
        "record": {
          ".validate": "newData.hasChildren(['memo', 'amount', 'updatedAt']) && newData.child('memo').isString() && newData.child('memo').val().length <= 120 && newData.child('amount').isNumber() && newData.child('amount').val() >= 0 && newData.child('amount').val() <= 999999 && newData.child('updatedAt').isNumber()"
        }
      }
    }
  }
}

※ Firebaseルールには && や <= を使用します。上の表示をコピーすると正しい記号が入ります。ルールは親の .read/.write が false、試験パスの自分のUIDのみ許可です。
